### 🚀 Highlighted Systems & Engineering

- **[CodeOwl](https://github.com/rafinulhuq/codeowl)** — Developer activity & telemetry platform. Ingests heartbeats directly from custom VS Code extensions (`VSIX`) and Zed editor (`stdio LSP bridge`), computing rolling coding metrics with edge-safe session handling.
- **[OpenVett / Talvyn](https://github.com/teamacmeai/openvett)** — AI-powered technical hiring & assessment engine. Features automated test generation, anti-fraud timed candidate portals, and local Ollama model evaluation on Docker Compose + pgvector.
- **TaskFlow** — High-concurrency Go worker pool backend managing asynchronous distributed jobs, terminal telemetry streams, and graceful worker shutdown.
- **Findea Backend** — Scalable multi-tenant e-commerce backend built with NestJS, PostgreSQL, Redis, and automated CI/CD pipelines.
- **[SquareAtom Studio](https://squareatom.tech)** — Suite of local-first, privacy-focused Flutter Android applications (Finbit, Moonpage, iMuhsin, Since, Comet).
